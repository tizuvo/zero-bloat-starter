Questions

Frequently asked questions

Powered by native HTML disclosure elements — keyboard accessible and zero JavaScript required.

How fast can I customize this template for my own brand?

Update the custom properties in public/assets/css/tokens.css, swap the geometric SVG mark, and edit the semantic HTML copy. Most teams publish a branded version in under five minutes.

Can I add custom self-hosted fonts without breaking the strict CSP?

Yes. Place your WOFF2 font files inside public/assets/fonts/ and uncomment the @font-face block at the top of tokens.css. Because font-src is set to 'self', local fonts load cleanly with zero third-party requests.

Why is there no framework or build step?

Modern CSS and HTML natively handle custom properties, fluid type, accordions, and cross-document view transitions. Removing bundlers eliminates dependency rot and keeps page weight minimal.

How do I verify security headers and SEO before deploying?

Run npm test to execute the built-in Node verification suite, or start the local preview server with npm run dev and run npx @tizuvo/audit against your local or production URL.
